# Introduction

The **Human Locomotion Specification (HLS)** describes procedural animation of
human movement in a structured, implementation-agnostic way.

This documentation is the source of truth: it lives as Markdown in Git, reads
cleanly on GitHub, and renders here as a browsable site.

Start with the [Principles](../01-principles/index.md), then explore the
[Skeleton](../02-skeleton/index.md) and the [Gait Cycle](../04-gait-cycle/index.md).
