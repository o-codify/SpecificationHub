# Tool Check

This document verifies that an AI agent can create a branch, write a Markdown document, and commit it without changing `main`.

Expected behavior:

- the document exists on `ai/tool-check`;
- the document does not exist on `main`;
- suggestions can show this branch as a proposed change.
